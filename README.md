# daily-news-brief

自動化排程產生的每日資訊彙整報告，每天約台灣時間 07:00 與 22:00 各執行一次。

任務會造訪一批公開的科技/總經/創投資訊來源網站（YouTube頻道、機構投資人研究網站、創投與科技評論部落格等），找出同一時間點被多個不同來源同時報導/討論的共同主題，整理成 HTML 報告。

- 報告存放於 [`daily-news-reports/`](daily-news-reports/) 目錄，檔名格式為 `{日期}_{時間}.html`
- 報告索引請見 [`daily-news-reports/index.html`](daily-news-reports/index.html)
- 本 repo 透過 GitHub Pages 對外發佈，網址：https://i45115515-design.github.io/daily-news-brief/

## 注意事項

本 repo 為公開實驗性 repo，僅存放公開新聞標題、日期與連結等公開資訊，不含任何個人或敏感資料。報告內容僅供每日追蹤參考，不構成投資建議。
